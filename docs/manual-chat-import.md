# Ручной импорт старых Wazzup/amoCRM переписок

Wazzup не отдаёт историю старых чатов через API. Поэтому для старой базы используем ручной/полуавтоматический inbox.

## Куда класть файлы

Клади файлы сюда:

```text
private-data/manual-chats/inbox/
```

`private-data/` добавлен в `.gitignore`, реальные переписки и персональные данные не уйдут в GitHub.

## Какие форматы можно кидать

Поддерживаются:

```text
.txt
.md
.csv
.json
.html
.htm
```

Лучший формат — обычный `.txt` или `.md`.

## Как копировать переписку вручную

### Вариант 1 — самый быстрый

1. Открой сделку в amoCRM.
2. Открой чат Wazzup внутри сделки.
3. Выдели переписку мышкой/клавиатурой.
4. Скопируй.
5. Вставь в файл:

```text
private-data/manual-chats/inbox/lead-123456-wa.txt
```

Желательный формат внутри файла:

```text
Клиент: Здравствуйте, хотим Турцию, 2 взрослых и 2 детей.
Агент: Добрый день. Подскажите возраст детей и даты вылета?
Клиент: 5 и 11 лет, конец июня.
Агент: Приняла, сейчас подберу 2–3 варианта.
```

Если скопируется без ролей — тоже можно, но качество разбора будет ниже.

### Вариант 2 — HTML

Если браузер/amo позволяет сохранить страницу/фрагмент как HTML — клади `.html` в inbox. Скрипт вытащит текст.

### Вариант 3 — CSV/таблица

Если получится выгрузить таблицей, клади `.csv`. Главное, чтобы в строках были дата/автор/текст.

## Как запустить один проход

```bash
npm run manual:ingest
```

Скрипт:

1. берёт все файлы из `inbox`,
2. обезличивает телефоны/email/длинные номера/ссылки,
3. скорит диалог,
4. переносит исходник в `processed`,
5. пишет результат в `scored`.

## Как запустить бесконечный режим

```bash
npm run manual:watch
```

Он будет каждые 30 секунд проверять inbox и обрабатывать новые файлы.

## Куда смотреть результаты

```text
private-data/manual-chats/redacted/       обезличенные тексты
private-data/manual-chats/scored/*.json   разбор каждого диалога
private-data/manual-chats/scored/index.jsonl
private-data/manual-chats/scored/summary.json
private-data/manual-chats/processed/      обработанные исходники
private-data/manual-chats/failed/         файлы с ошибками
```

## Что выдаёт скоринг

Для каждого диалога:

- балл 0–100;
- готовность: `good / control_needed / risk`;
- тип клиента;
- возражения;
- сильные ходы агента;
- ошибки агента;
- пропущенные вопросы;
- риск-флаги;
- фразы клиента для тренажёра;
- seed сценария для нейроклиента;
- короткий вывод руководителю.

## Что делать пачками

Ручной минимум для старта:

```text
20 успешных сделок
20 слитых сделок
20 длинных WhatsApp-переписок
20 звонков Mango
```

Практический ритм:

1. открыть 10–20 сделок за день;
2. скопировать переписки в `.txt`;
3. положить в `inbox`;
4. оставить `npm run manual:watch`;
5. смотреть `summary.json` и top mistakes.

## Важное

Старую Wazzup-историю через API не ждём. Webhook включаем только для новых сообщений, а старый корпус добираем этим ручным способом + Mango-звонками.
