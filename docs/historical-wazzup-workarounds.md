# Нормальный обход старых Wazzup-переписок без API

Wazzup подтвердил: старую историю сообщений через API они не отдают. Значит есть два рабочих обхода.

## Вариант A — видео переписок → OCR → скоринг

Это быстрее всего без доступа к браузерной сессии.

### Как записывать видео

1. Открываешь amoCRM/Wazzup.
2. Открываешь сделку/чат.
3. Медленно скроллишь переписку сверху вниз.
4. Переходишь к следующей сделке.
5. Повторяешь.

Правила записи:

- масштаб браузера 100–125%;
- ширина окна побольше;
- не скроллить слишком быстро;
- задержка 1–2 секунды на каждом экране;
- лучше 10–20 диалогов на одно видео, не 100 в одном монстре;
- называй видео: `won-turkey-family-001.mp4`, `lost-egypt-price-001.mp4`.

### Как обработать видео

```bash
npm run video:ocr -- private-data/video-inbox/chats.mp4 --fps 0.5 --ocr
```

Что делает скрипт:

1. ffmpeg режет видео на кадры;
2. дубли кадров выкидываются;
3. GPT Vision вытаскивает текст переписки;
4. реконструированный текст кладётся в:

```text
private-data/manual-chats/inbox/video-*.md
```

5. дальше обычный watcher/cron скорит диалог.

### Когда использовать видео

Использовать, если:

- нет нормальной браузерной сессии на сервере;
- нужно быстро прогнать пачку старых диалогов;
- допускаем 80–90% качество извлечения, потом чистим важные кейсы.

Минусы:

- OCR может ошибаться;
- если быстро скроллить — потеряем сообщения;
- роли клиент/агент иногда придётся восстанавливать моделью.

## Вариант B — браузерный робот в amoCRM

Это правильнее, но требует сессию amoCRM.

Схема:

```text
amoCRM API → список URL сделок → Playwright Chromium → открыть сделку → снять текст/скрин → сохранить → скорить
```

### Что уже готово

Экспорт URL сделок:

```bash
npm run amocrm:lead-urls -- --limit 200
```

Пишет:

```text
private-data/browser-scrape/lead-urls.txt
```

Браузерный сканер:

```bash
npm run amocrm:browser-scrape -- --limit 50 --wait-ms 5000
```

Пишет:

```text
private-data/browser-scrape/00001-<lead_id>/
  body.txt
  page.html
  page.png
  meta.json
```

Если на странице будет виден Wazzup-чат, текст автоматически попадёт в:

```text
private-data/manual-chats/inbox/browser-<lead_id>.txt
```

и будет скориться.

### Что блокирует прямо сейчас

На сервере браузер без твоей сессии видит только login page amoCRM:

```text
Забыли?
Войти Регистрация
Чужой компьютер
```

То есть робот работает, но ему нужен залогиненный профиль.

### Как дать сессию без пароля в чат

Лучший вариант — поднять remote/noVNC-браузер, ты один раз заходишь в amoCRM сам, потом робот использует профиль.

Альтернативы:

1. дать временный логин/пароль и 2FA — не люблю, но быстро;
2. экспортировать cookies/storage state из своего браузера — менее удобно;
3. запустить Playwright-скрипт на твоём компьютере, где amoCRM уже открывается.

## Мой выбор

Для скорости: начать с видео.

Для продукта: параллельно настроить браузерного робота с залогиненной сессией.

Идеальная схема:

```text
старые чаты: видео/OCR + браузерный робот
новые чаты: Wazzup webhooks
звонки: Mango MP3
сделки/статусы: amoCRM API
```
